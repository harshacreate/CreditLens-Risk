# CreditLens-Risk — Lending Research Prototype

A synthetic loan application exercise using income, loan size, debt-to-income, credit history, delinquencies, employment duration, utilization, and age.

Synthetic data only. Research/education only. These generated labels are not a validated credit policy. No lending decision should be made from this prototype; human review and jurisdiction-specific fairness evaluation are required. Age-band metrics are diagnostics only.

Run: `python -m creditlens.train --json`; tests: `python -m pytest -q`.
